# Screenshots Needed

## Required Screenshots

### 1. openai-demo.png
**What to capture:** Main interface with task selection

**How to take:**
1. Navigate to http://localhost:8002 (or live deployment URL)
2. Take a full-page screenshot showing:
   - Header banner with demo mode notice
   - API status indicator (top right)
   - Feature list
   - Sample data buttons
   - Text input area with sample text
   - Task selection buttons
3. Save as `openai-demo.png` in this directory

### 2. openai-results.png
**What to capture:** Processing results

**How to take:**
1. Select "Business Report" sample
2. Choose "Summarize" task
3. Click "Process Text" button
4. Wait for results to display
5. Take a screenshot showing:
   - Original text (if visible)
   - Processing result
   - Demo mode indicator at bottom
6. Save as `openai-results.png` in this directory

## Optional: Multiple Task Screenshots

Consider taking additional screenshots showing:
- `openai-sentiment.png` - Sentiment analysis results
- `openai-keywords.png` - Keyword extraction with tags
- `openai-translate.png` - Translation to Spanish/French

## Screenshot Tools

- **macOS:** Cmd + Shift + 4
- **Windows:** Snipping Tool or Windows + Shift + S
- **Linux:** Flameshot, GNOME Screenshot, or `scrot`
- **Browser Extension:** Awesome Screenshot, Full Page Screen Capture

## Image Specifications

- Format: PNG
- Recommended width: 1200-1600px
- Quality: High (for clarity)
- File size: Keep under 2MB each

## After Creating Screenshots

1. Replace this README.md with actual images
2. Update the main README.md to ensure image paths are correct
3. Verify images display properly in GitHub
4. Commit and push to repository
