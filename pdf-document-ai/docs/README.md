# Screenshots Needed

## Required Screenshots

### 1. pdf-demo.png
**What to capture:** Main interface before processing

**How to take:**
1. Navigate to http://localhost:8001 (or live deployment URL)
2. Take a full-page screenshot showing:
   - Header banner with demo mode notice
   - Feature list
   - Upload area
   - Both buttons
3. Save as `pdf-demo.png` in this directory

### 2. pdf-results.png
**What to capture:** Analysis results after clicking "Try with Sample Invoice"

**How to take:**
1. Click "Try with Sample Invoice" button
2. Wait for results to display
3. Scroll to show all sections
4. Take a screenshot showing:
   - Document statistics (pages, words, characters)
   - Extracted emails (highlighted in code blocks)
   - Phone numbers
   - Dates
   - Currency amounts
   - Key sections
5. Save as `pdf-results.png` in this directory

## Screenshot Tools

- **macOS:** Cmd + Shift + 4
- **Windows:** Snipping Tool or Windows + Shift + S
- **Linux:** Flameshot, GNOME Screenshot, or `scrot`
- **Browser Extension:** Awesome Screenshot, Full Page Screen Capture

## Image Specifications

- Format: PNG
- Recommended width: 1200-1600px
- Quality: High (for clarity)
- File size: Keep under 2MB each

## After Creating Screenshots

1. Replace this README.md with actual images
2. Update the main README.md to ensure image paths are correct
3. Verify images display properly in GitHub
4. Commit and push to repository
