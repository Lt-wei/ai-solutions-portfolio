# Screenshots Needed

## Required Screenshots

### 1. excel-demo.png
**What to capture:** Main interface with the upload area and "Try with Sample Data" button

**How to take:**
1. Navigate to http://localhost:8000 (or live deployment URL)
2. Take a full-page screenshot showing:
   - Header banner
   - Feature list
   - Upload area
   - Both buttons
3. Save as `excel-demo.png` in this directory

### 2. excel-output.png
**What to capture:** The generated Excel file opened in Excel/Google Sheets

**How to take:**
1. Click "Try with Sample Data" button
2. Download the generated Excel file
3. Open in Microsoft Excel or Google Sheets
4. Take a screenshot showing:
   - Formatted header row (blue background)
   - Sample data rows
   - Proper column widths
   - Currency formatting
5. Save as `excel-output.png` in this directory

## Screenshot Tools

- **macOS:** Cmd + Shift + 4
- **Windows:** Snipping Tool or Windows + Shift + S
- **Linux:** Flameshot, GNOME Screenshot, or `scrot`
- **Browser Extension:** Awesome Screenshot, Full Page Screen Capture

## Image Specifications

- Format: PNG
- Recommended width: 1200-1600px
- Quality: High (for clarity)
- File size: Keep under 2MB each

## After Creating Screenshots

1. Replace this README.md with actual images
2. Update the main README.md to ensure image paths are correct
3. Verify images display properly in GitHub
4. Commit and push to repository
